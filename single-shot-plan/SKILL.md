## hỏi câu hỏi trước khi tạo file plan
- Luôn hỏi toàn bộ trước để làm rõ vấn đề.
- Cho biết chi tiết nên sửa file nào, dòng nào, nội dung ra sao.
- Tạo luôn cả 1 file .bat để sửa những file cần thiết (delete rồi tạo file mới)
- Sau đó chỉ tạo 1 file plan mới, không edit file plan.
